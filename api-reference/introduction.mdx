The Acme API is a REST API that accepts and returns JSON.

| Environment | Base URL |
| --- | --- |
| Sandbox | `https://sandbox.api.example.com/v1` |
| Production | `https://api.example.com/v1` |

Authenticate every request with a bearer token. See [Authentication](/docs/get-started/authentication).

The endpoint pages in this tab are generated from `api-reference/openapi.yaml`. Each one has a **Try it** button that sends a real request.
