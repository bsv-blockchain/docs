The site publishes every page of these docs as plain Markdown, so an AI agent can read the guides before it writes BSV code. It works with any AI tool that can open a web address or read pasted text, with no setup. Without the docs, an agent can write code for the wrong network or put a private key in your code. At the end, your agent knows where to find the pages it needs, and your project has rules that keep it on testnet.

## Find the docs in Markdown

The site publishes the docs in three Markdown forms:

| File | Address | What it holds |
|------|---------|---------------|
| `llms.txt` | `https://bsvblockchain.com/docs/llms.txt` | The list of every page, grouped as in the sidebar, with its title, the address of its Markdown copy and a one line description |
| `llms-full.txt` | `https://bsvblockchain.com/docs/llms-full.txt` | Every page in full, in one file |
| Markdown copy of a page | The page address with `.md` in place of the final slash, for example `https://bsvblockchain.com/docs/get-started/quick-start-browser.md` | One page in full |

Point the agent at `llms.txt` first, so it reads only the pages it needs. Use `llms-full.txt` when your tool loads a whole file into its context at once.

## Give a page to your agent

Every page has a **Copy page** menu. These options give the page to a chat:

- Select **Copy page** to copy the page as Markdown, ready to paste into a chat.
- Select **View as Markdown** to open the `.md` copy of the page.
- Select **Open in ChatGPT**, **Open in Claude** or **Open in Perplexity** to start a chat about the page in that tool.

For an agent that reads web addresses, such as [Claude Code](https://code.claude.com/docs/en/overview), put the address in your request:

```text
Read https://bsvblockchain.com/docs/llms.txt, then read the .md copies of the pages you need before you write BSV code.
```

To give the agent search across all pages instead, use **Copy MCP server URL**, **Connect to Cursor** or **Connect to VS Code** in the same menu, as in [Connect your AI tool with MCP](/build-with-ai/simple-mcp/).

## Add the rules to your project

Add these rules to the instructions file your agent reads in every session, such as `CLAUDE.md` at the root of the project for Claude Code:

```markdown CLAUDE.md
## BSV rules

- Read the BSV docs at https://bsvblockchain.com/docs/llms.txt before you write BSV code, and follow their guides.
- Build on testnet. Before a payment, check that the `network` field returned by `wallet.getNetwork()` is `testnet`.
- In an app, connect to the user's wallet with `WalletClient` from `@bsv/sdk`, so no private key goes in the code.
- Never ask the user for a private key or a recovery phrase.
- Ask the user to get testnet coins from the faucet at https://bsvfaucet.com and to approve each payment in BSV Desktop. These steps need a person.
- Never send a payment on Mainnet unless the user asks for it, since a payment cannot be undone.
```

These rules come from [Send a payment from a web app](/get-started/quick-start-browser/). In that guide, the wallet in [BSV Desktop](https://desktop.bsvb.tech/) holds the keys, chooses the coins and signs, and a person signs in to the faucet and approves the payment.
