The SDK API reference lists every method of the two wallet objects of `@bsv/simple`, a helper library on top of `@bsv/sdk`, with the options, defaults and errors the code shows. Use it to look up a method while you build, and the guides to see how the methods fit together. This page was written against `@bsv/simple` 0.7.2 with `@bsv/sdk` 4.0.1.

## Wallet objects

The two objects share the methods of `WalletCore` and seven modules, and `ServerWallet` adds the deprecated `receivePayment()`. They differ in where your code runs and who holds the key:

<BlueTable>

| Wallet object | Where your code runs | How you create it | Who holds the key |
| --- | --- | --- | --- |
| `BrowserWallet` | A web app | `createWallet()` from `@bsv/simple/browser` | The user's <Hint tip="BSV Request for Comments 100, the standard interface between apps and wallets">BRC-100</Hint> wallet |
| `ServerWallet` | Node.js 22 or later | `ServerWallet.create()` from `@bsv/simple/server` | Your server |

</BlueTable>

The Wallet API and the HTTP APIs of BSV services are in the Reference tab. For the main SDK, `@bsv/sdk`, start from the [TypeScript SDK](/sdk/typescript/) page. For the Go SDK, see its [documentation on pkg.go.dev](https://pkg.go.dev/github.com/bsv-blockchain/go-sdk), and for the Python SDK, its [repository on GitHub](https://github.com/bsv-blockchain/py-sdk).
