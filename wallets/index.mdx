A wallet holds your keys and signs what your apps ask for, so no private key goes in your code. The BSV Association makes two wallets, and both implement <Hint tip="BSV Request for Comments 100, the standard interface between apps and wallets">BRC-100</Hint>.

## Choose a wallet

<BlueTable>

| Wallet | Runs on | Use it to | Get it |
|---|---|---|---|
| [BSV Desktop](/wallets/bsv-desktop/) | macOS, Windows and Linux | Build and test apps on your computer | [desktop.bsvb.tech](https://desktop.bsvb.tech/) |
| [BSV Browser](/wallets/bsv-browser/) | iOS and Android | Use BSV web apps and pay from your phone | [mobile.bsvb.tech](https://mobile.bsvb.tech) |

</BlueTable>

## Use BSV Desktop on testnet for these docs

The guides in these docs use BSV Desktop on testnet, where coins are free and have no value.

<Callout type="warning">
  A new BSV Desktop wallet opens on Mainnet, where coins have real value. Switch it to testnet before you follow a guide, as the Quick Start shows. Every guide uses testnet, except the one about moving to Mainnet.
</Callout>

## Back up your wallet

Back up a wallet before it holds coins you care about. For BSV Desktop, follow [Back up and recover a wallet](/wallets/backup-recovery/). BSV Browser explains its backup options on its own page.

## Build your own wallet

To build a wallet instead of using one, follow [Build a wallet](/wallet-dev/). To find other BRC-100 wallets, see the wallet directory at [brc100.org](https://brc100.org).
