A working app shows how the pieces of BSV fit together. These demos range from a debugging tool that runs in your browser to a file exchange between two wallets, and the code of each one is in the [bsv-blockchain-demos](https://github.com/bsv-blockchain-demos) organization on GitHub.

## Which demo to start with

Each demo shows a different part of BSV:

    Share an encrypted file between two wallet identities, with <Hint tip="Universal Hash Resolution Protocol, content storage addressed by the hash of the file">UHRP</Hint> storage and an audit timeline.
  </Card>
  <Card title="Time Anchor" href="/showcase/time-anchor/">
    Record the hash of a file on the blockchain and find it again through an <Hint tip="Built from topic managers, which decide what is admitted, and lookup services, which query what was admitted.">overlay service</Hint>.
  </Card>
  <Card title="BEEF Inspector" href="/showcase/beef-inspector/">
    Read a <Hint tip="Background Evaluation Extended Format (BRC-62)">BEEF</Hint> payload and see the transaction inside it, to debug what your app receives.
  </Card>
</CardGroup>

</div>
