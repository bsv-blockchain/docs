The **BEEF Inspector** is a browser tool that reads a transaction packaged as <Hint tip="Background Evaluation Extended Format (BRC-62)">BEEF</Hint> and shows what is inside it: the transaction ID, the size, the number of inputs and outputs, and the scripts of any input that fails. The source code is in [bsv-blockchain-demos/beef-inspector](https://github.com/bsv-blockchain-demos/beef-inspector).

## When to use it

Use the BEEF Inspector when you have a BEEF, from an app, a wallet or your own code, and you need to see what it holds or why it fails to parse or verify. If you only have a testnet transaction ID, [Try BSV in your browser](/get-started/try-it/) looks it up for you.

## How it works

You paste a BEEF as hex, and the tool reads it with `@bsv/sdk`.

### What it shows

The tool lists these results:

| Result | What it shows | When it appears |
|---|---|---|
| **Transaction Info** | The transaction ID, version, number of inputs and outputs, lock time and serialized size. The size is the transaction alone, not the whole BEEF payload. | Always |
| **Error** | The error raised while parsing or verifying the BEEF. | When parsing or verification fails |
| **BEEF Structure Log** | A log of the BEEF structure: the transaction fields and, for each input, the source transaction ID and the unlocking script. | When verification raises an error |
| **Script Execution Errors** | For each input whose script fails when the tool runs it, the <Hint tip="The part of a transaction output that sets the condition to spend it">locking script</Hint> and the unlocking script as assembly, with the error details. | When an input script fails |
| **Signature Hash Types** | A tooltip with the signature hash flags of a value in those scripts that looks like a signature. | When you hover over such a value |

### Which network it verifies against

Parsing runs in your browser. To verify the Merkle proofs, the tool uses the default chain tracker of `@bsv/sdk`, which requests Mainnet block headers from WhatsOnChain. The tool has no setting for the network or the tracker.

<Callout type="info">
  A testnet BEEF always shows **INVALID**, because its proofs do not match Mainnet block headers, and the error comes from the failed lookup. The transaction details and the structure log still appear, so you can still read a testnet BEEF.
</Callout>

### Read the validation result

The **Validation Result** badge shows **VALID** when `Transaction.verify()` finishes without raising an error. The tool ignores the value that the method returns, so a transaction that the SDK reports as not valid can still show **VALID**. Use the badge as a sign that the BEEF parsed and the verification ran, and call `Transaction.verify()` in your own code when you need the verdict. The console snippet in [Try BSV in your browser](/get-started/try-it/) shows that check against testnet.

## Run it locally

The tool needs Node.js 22 and npm. It has no server, database or environment file, and it does not connect to a wallet. `npm ci` installs `@bsv/sdk` 1.7.6.

<Steps>
  <Step title="Start the tool">
    Clone the repository, install the dependencies and start the development server, all in a terminal:

    ```bash
    git clone https://github.com/bsv-blockchain-demos/beef-inspector.git
    cd beef-inspector
    npm ci
    npm run dev -- --host 127.0.0.1
    ```
  </Step>
  <Step title="Open the page">
    Open the address on the `Local` line that the terminal prints, in your browser:

    ```text
    ➜  Local:   http://127.0.0.1:8080/
    ```

    The port can differ if 8080 is taken. The page is headed **BSV Transaction Debugger**.
  </Step>
  <Step title="Analyze a BEEF">
    Paste a hex-encoded BEEF into **Transaction Hex (BEEF Format)** and click **Analyze Transaction**.
  </Step>
</Steps>

The input must be BEEF. A transaction ID or a raw transaction in hex is not accepted, and the page shows a **Parse Error** with the reason.

## How it is built

The tool is a Vite and React app, and `src/pages/Index.tsx` holds the parsing, the verification and the collection of diagnostics. The code is under the Open BSV License version 6, which limits its use to the BSV blockchain, and the full terms are in [LICENSE.txt](https://github.com/bsv-blockchain-demos/beef-inspector/blob/main/LICENSE.txt).
