This page helps you decide whether to run your own SV Node, then sends you to the install, configure and RPC pages. SV Node is node software for the BSV network. A release ships `bitcoind`, the node itself, `bitcoin-cli` to control it and `bitcoin-tx` to build transactions. It connects to the peer-to-peer network, validates and relays transactions and blocks, stores the chain, and exposes an RPC interface, an optional REST interface and optional ZeroMQ notifications. Miners run it.

## Decide whether you need your own node

Non-mining entities, such as exchanges and apps, do not need to run a node for daily operation. Use <Hint tip="Simplified Payment Verification: a client checks transactions against block headers without storing the whole chain.">SPV</Hint> wallets, and services such as <Hint tip="A transaction broadcast API of miners. The backend of the demo forwards BEEF transactions to it">ARC</Hint> that process transactions for you. Run SV Node when you mine, or when you want a node of your own with its RPC interface.

## Know the networks

The same software runs on Mainnet, testnet and regtest, and on the Scaling Test Network with `-stn`. On regtest you mine blocks on demand with the `generate` RPC method, so it needs no peers. Start on testnet or regtest: Mainnet coins have real value, so a mistake costs real funds, and its chain is far larger than testnet's. Regtest needs no download and no peers.
