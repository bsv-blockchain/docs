SV Node is node software for the BSV network. A release ships `bitcoind`, the node itself, `bitcoin-cli` to control it and `bitcoin-tx` to build transactions. It connects to the peer-to-peer network, validates and relays transactions and blocks, stores the chain, and exposes an RPC interface, an optional REST interface and optional ZeroMQ notifications. Miners run it, and the existing documentation lists it as the minimum a miner needs.

## Decide whether you need your own node

The existing BSV documentation recommends that non-mining entities, such as exchanges and apps, move away from daily reliance on the node software, because of the traffic on the network. It points them to <Hint tip="Simplified Payment Verification: a client checks transactions against block headers without storing the whole chain.">SPV</Hint> wallets, and to services such as ARC that process transactions for you. Run SV Node when you mine, or when you want a node of your own with its RPC interface.

## Know the networks

The same software runs on Mainnet, testnet and regtest, and on the Scaling Test Network with `-stn`. On regtest you mine blocks on demand with the `generate` RPC method, so it needs no peers. Start on testnet or regtest, because a Mainnet node has to download the whole chain.
