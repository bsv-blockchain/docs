SV Node exposes a JSON-RPC API for reading the chain, relaying transactions, mining and managing its wallet. The tables below list the methods that `bitcoin-cli help` shows in SV Node 1.2.3, grouped as the node groups them, with the first line of each method's help text. Run `bitcoin-cli help <method>` for the arguments and the result of one method.

<Callout type="warning">
RPC gives full control of the node and its wallet. It can stop the node, dump private keys and spend funds. Keep the port on `127.0.0.1` or a private network and never publish it.
</Callout>

## Call the API

Enable the server with `server=1` and credentials in `bitcoin.conf`, as described in [Configure SV Node](/nodes/sv-node/configuration). The default RPC port is 8332 on Mainnet and 18332 on testnet and regtest. Send a JSON-RPC POST with HTTP basic authentication.

```bash
curl --user RPC_USERNAME:RPC_PASSWORD -H "content-type: application/json" -d '{"jsonrpc":"1.0","id":"1","method":"getblockcount","params":[]}' http://127.0.0.1:18332/
```

Replace `RPC_USERNAME` and `RPC_PASSWORD` with the `rpcuser` and `rpcpassword` values of your `bitcoin.conf`. On a new regtest chain the node answers `{"result":0,"error":null,"id":"1"}`, where the result is the block count. Wrong credentials return HTTP 401. `bitcoin-cli` takes the same method names and positional arguments, for example `bitcoin-cli -regtest getblockcount`.

<Callout type="note">
`getinfo` still works in 1.2.3 but its help text marks it deprecated. Use `getblockchaininfo`, `getnetworkinfo` and `getmininginfo` instead.
</Callout>

### Blockchain

These methods read blocks, headers, the mempool and proofs, and verify or prune the chain:

<BlueTable>

| Method | Description |
| --- | --- |
| `checkjournal` | Checks for consistency between the TX memory pool and the block assembly journal. |
| `getbestblockhash` | Returns the hash of the best (tip) block in the longest blockchain. |
| `getblock "blockhash" ( verbosity )` | Returns a block by hash. The verbosity sets raw hex, header fields or decoded transactions. |
| `getblockbyheight height ( verbosity )` | Returns a block by height. The verbosity works as in `getblock`. |
| `getblockchaininfo` | Returns an object containing various state info regarding blockchain processing. |
| `getblockcount` | Returns the number of blocks in the longest blockchain. |
| `getblockhash height` | Returns hash of block in best-block-chain at height provided. |
| `getblockheader "hash" ( verbosity )` | If verbosity is 0, false or RAW_HEADER, returns a string that is serialized, hex-encoded data for blockheader 'hash'. |
| `getblockstats blockhash ( stats )` | Compute per block statistics for a given window. |
| `getblockstatsbyheight height ( stats )` | Compute per block statistics for a given window. |
| `getchaintips` | Return information about all known tips in the block tree, including the main chain as well as orphaned branches. |
| `getchaintxstats ( nblocks blockhash )` | Compute statistics about the total number and rate of transactions in the chain. |
| `getdifficulty` | Returns the proof-of-work difficulty as a multiple of the minimum difficulty. |
| `getmempoolancestors txid (verbose)` | Returns all in-mempool ancestors of a transaction that is in the mempool. |
| `getmempooldescendants txid (verbose)` | Returns all in-mempool descendants of a transaction that is in the mempool. |
| `getmempoolentry txid` | Returns mempool data for a given transaction. |
| `getmempoolinfo` | Returns details on the active state of the TX memory pool. |
| `getmerkleproof "txid" ( blockhash )` | Deprecated, use `getmerkleproof2`. Returns a Merkle proof for a transaction. |
| `getmerkleproof2 "blockhash" "txid"   ( includeFullTx targetType format )` | Returns a Merkle proof for a transaction by transaction ID, as a list of Merkle tree hashes. |
| `getrawmempool ( verbose )` | Returns all transaction ids in memory pool as a json array of string transaction ids. |
| `getrawnonfinalmempool` | Returns all transaction ids in the non-final memory pool as a json array of string transaction ids. |
| `gettxout "txid" n ( include_mempool )` | Returns details about an unspent transaction output. |
| `gettxoutproof ["txid",...] ( blockhash )` | Returns a hex-encoded proof that a transaction was included in a block. |
| `gettxouts txidVoutList returnFields ( include_mempool )` | Returns details about an unspent transaction output. |
| `gettxoutsetinfo` | Returns statistics about the unspent transaction output set. |
| `preciousblock "blockhash"` | Treats a block as if it were received before others with the same work. |
| `pruneblockchain` | Prunes blocks up to a height or a Unix timestamp. Needs `-prune`. |
| `rebuildjournal` | Forces the block assembly journal and the TX mempool to be rebuilt to make them consistent with each other. |
| `verifychain ( checklevel nblocks )` | Verifies blockchain database. |
| `verifymerkleproof "proof"` | Verifies a given Merkle proof in JSON format and returns true if verification succeeded. |
| `verifytxoutproof "proof"` | Verifies that a proof points to a transaction in a block, returning the transaction it commits to. |

</BlueTable>

| `decoderawtransaction "hexstring"` | Return a JSON object representing the serialized, hex-encoded transaction. |
| `decodescript "hexstring"` | Decode a hex-encoded script. |

| `signrawtransaction "hexstring" ( [{"txid":"id","vout":n,"scriptPubKey":"hex","redeemScript":"hex"},...] ["privatekey1",...] sighashtype )` | Sign inputs for raw transaction (serialized, hex-encoded). |
