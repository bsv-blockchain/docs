Use the guides to add BSV to an app you are building. They run on testnet wherever a wallet is involved, so you can try them without real funds, except the guide that moves your app to Mainnet, which ends with real BSV. If you have not sent a payment yet, start with [Send a payment from a web app](/get-started/quick-start-browser/).

## Add one capability to your app

<Visibility for="agents">

| [Store data and files](/guides/data-storage/) | Put data in a transaction output through the user's wallet and read it back. |
| [Send messages between users](/guides/messaging/) | Send encrypted messages and payments with <Hint tip="Holds each message until its recipient reads it">MessageBox</Hint>. |
| [Track transactions with overlays](/guides/overlays/) | Index your app's transactions in an <Hint tip="Built from topic managers, which decide what is admitted, and lookup services, which query what was admitted.">overlay</Hint> and look them up by service. |
| [Digital product passports on BSV](/guides/digital-product-passports/) | Map a digital product passport onto BSV and check a test passport offline. |

</Visibility>
