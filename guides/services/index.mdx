Your app sends its transactions through Arcade, the BSV Association's transaction broadcaster. If you want to run a node or a service yourself, each project documents that on its own, and this page links to them.

## Send transactions from your app

To send a signed transaction and follow it until a miner includes it in a block, see [Broadcast with Arcade](/guides/services/broadcasting/).

## Run a service yourself

These links take you to each project's documentation and repository, where you find how to install and run it.

| To run | Start here |
|--------|------------|
| Teranode, the next generation node | [Teranode docs](https://bsv-blockchain.github.io/teranode/) |
| SV Node, the current node | [bitcoin-sv/bitcoin-sv](https://github.com/bitcoin-sv/bitcoin-sv) |
| Arcade, the transaction broadcaster | [arcade](https://github.com/bsv-blockchain/arcade) |
| An overlay service | [go-overlay-services](https://github.com/bsv-blockchain/go-overlay-services) and the [ts-stack docs](https://bsv-blockchain.github.io/ts-stack/) |
