---
title: Getting Started
---

<Steps>
  <Step title="Edit content">
    A page is any `.md`/`.mdx` file with a frontmatter block -
    `docs/` is a convenient place to put most of them, but not a
    requirement.
  </Step>
  <Step title="Update navigation">
    Add the page's path (without extension) to `writedocs.json` - a page
    under `docs/` is referenced with that prefix, e.g. `docs/guides/x`
    for `docs/guides/x.mdx`.
  </Step>
  <Step title="Preview">
    Run `writedocs dev` and open the printed local URL.
  </Step>
</Steps>
