A wallet holds your keys and signs what your apps ask for, so no private key goes in your code. This page helps you pick a wallet to use, and points you to the pages for backing it up and for building your own.

## Pick a wallet to use

BSV has two wallets from the BSV Association, one for the computer and one for the phone. Both implement <Hint tip="BSV Request for Comments 100, the standard interface between apps and wallets">BRC-100</Hint>.

| | BSV Desktop | BSV Browser |
|---|---|---|
| Runs on | macOS, Windows and Linux | iOS and Android |
| Use it to | Build and test apps on your computer | Use BSV web apps and pay from your phone |
| Where to get it | [desktop.bsvb.tech](https://desktop.bsvb.tech/) | [mobile.bsvb.tech](https://mobile.bsvb.tech) |

If you follow the guides in these docs, use BSV Desktop. Start with [Send a payment from a web app](/docs/get-started/quick-start-browser/).

<Callout type="warning">
  A new BSV Desktop wallet opens on Mainnet, where coins have real value. The guides use testnet, except the guide about Mainnet, and the Quick Start shows how to switch.
</Callout>

## Back up your wallet

A wallet keeps your keys on your device. Back up a BSV Desktop wallet before it holds coins you care about, as in [Back up and recover a wallet](/docs/wallets/backup-recovery/). The backup options of BSV Browser are on its [own page](/docs/wallets/bsv-browser/).

## Build your own wallet

To build a wallet instead of using one, follow [Build a wallet](/docs/wallet-dev/). To find other BRC-100 wallets, see the wallet directory at [brc100.org](https://brc100.org).
