The **BSV** blockchain implements the original Bitcoin protocol. Forked from Bitcoin Cash in 2018, BSV runs on the UTXO model with no fixed protocol limit on block size and a maximum transaction size of 1 GB.

On BSV, your app can send payments, issue tokens and prove data integrity, verify transactions without running a node, and leave the private keys with the user's wallet.

## How BSV Works

Design your app around four ideas:

- Ownership lives in **UTXOs**, unspent transaction outputs. You can handle each output on its own, without a global account state.
- Verification runs in your app through <Hint tip="Simplified Payment Verification"><strong>SPV</strong></Hint>. It lets your app check its own transactions with Merkle paths and block headers.
- Transactions travel in <Hint tip="Background Evaluation Extended Format (BRC-62)"><strong>BEEF</strong></Hint>, a format that bundles a transaction with the proofs needed for SPV validation.
- Wallet access goes through <Hint tip="BRC stands for Bitcoin Request for Comments, the standards process of BSV."><strong>BRC-100</strong></Hint>, the standard wallet-to-application interface that wallets such as **BSV Desktop** implement.

## Which Package to Use

Pair the foundation with the package for the side you build:

| **Package** | **What you get** |
|---|---|
| **Foundation**<br />`@bsv/sdk` | Keys, signatures, Script, transactions, BEEF and Merkle paths |
| **App**<br />`@bsv/simple` | Helpers for payments and tokens, connected to the user's wallet |
| **Wallet**<br />`@bsv/wallet-toolbox` | The pieces to build BRC-100 wallets |
