---
title: Authentication
description: How requests to the Acme API are authenticated.
---

Every request sends an API key in the `Authorization` header:

```http
Authorization: Bearer sk_test_...
```

## Environments

| Environment | Base URL | Key prefix |
| --- | --- | --- |
| Sandbox | `https://sandbox.api.example.com/v1` | `sk_test_` |
| Production | `https://api.example.com/v1` | `sk_live_` |

<Callout type="warning">
  Keys carry full access to your account. Keep them on your server, never in a browser or mobile app, and never commit them to git.
</Callout>

## Errors

A missing or invalid key returns `401 Unauthorized`:

```json
{
  "error": {
    "code": "unauthorized",
    "message": "Invalid API key."
  }
}
```
