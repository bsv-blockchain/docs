## Code

Fenced code blocks get highlighting and a copy button. Several blocks inside `<CodeGroup>` become tabs, labelled by the text after the language:

````mdx
<CodeGroup>
```bash cURL
curl https://api.example.com/v1/orders
```

```javascript Node.js
await fetch('https://api.example.com/v1/orders');
```
</CodeGroup>
````

The full list of components, with every option, is in the [Writedocs docs](https://preview.writedocs.io/docs/content/components/).
